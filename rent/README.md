# מערכת גביית שכר דירה

תוכנה מקומית לניהול הגבייה מהשוכרים: כמה כל דייר אמור להעביר בכל חודש, כמה הועבר בפועל ובאיזה
אמצעי תשלום (מזומן / צ׳ק / העברה בנקאית / ביט / הוראת קבע ועוד), ניהול החוזים עצמם וחיפוש חופשי
בתוך נוסח החוזים.

הכול רץ על המחשב שלך: אין ענן, אין הרשמה, אין תלויות להתקין. הנתונים נשמרים בקובץ SQLite מקומי.

---

## הרצה

דרישה יחידה: **Node.js בגרסה 22.5 ומעלה** (מגיע עם SQLite מובנה). בודקים אם הוא מותקן עם
`node -v`, ואם לא – מורידים את גרסת ה-LTS מ-<https://nodejs.org>.

### הדרך הקלה – לחיצה כפולה

* **Mac / לינוקס**: לחיצה כפולה על `start.command`
  (בפעם הראשונה ב-Mac: לחיצה ימנית ← Open ← Open, כדי לאשר הרצה).
* **Windows**: לחיצה כפולה על `start.bat`.

הדפדפן ייפתח לבד בכתובת <http://localhost:4173>. לסגירה – סוגרים את החלון השחור.

### או מהטרמינל

```bash
cd rent
node server.js
```

ואז נכנסים בדפדפן ל־<http://localhost:4173>.

בפעם הראשונה כדאי להיכנס ל**הגדרות → טעינת נתוני דמו** כדי לראות איך הכול נראה עם נתונים,
ואחר כך **הגדרות → מחיקת כל הנתונים** לפני שמתחילים באמת.

### אפשרויות הפעלה

| משתנה סביבה | ברירת מחדל | למה זה טוב |
|---|---|---|
| `PORT` | `4173` | פורט אחר |
| `RENT_DATA` | `./data` | תיקיית הנתונים (מסד הנתונים + קבצי החוזים) |
| `RENT_HOST` | `127.0.0.1` | `0.0.0.0` יאפשר גישה מהטלפון/מחשב אחר באותה רשת |
| `RENT_PASSCODE` | — | דורש קוד כניסה. **חובה** אם פותחים לרשת |

דוגמה לגישה מהטלפון באותו Wi-Fi:

```bash
RENT_HOST=0.0.0.0 RENT_PASSCODE=1234 node server.js
# ואז מהטלפון: http://<כתובת-ה-IP-של-המחשב>:4173
```

## מה יש במערכת

### צבעים ומצב תצוגה
המסך כהה כברירת מחדל – רקע שחור וכיתוב לבן. הצבעים אומרים מה קורה בלי לקרוא מספרים:

| צבע | משמעות |
|---|---|
| 🟢 ירוק | שמות הדיירים, וכל מה ששולם בפועל |
| 🔴 אדום | חוב בפיגור – עבר מועד התשלום ולא התקבל דבר |
| 🟠 כתום | מאחר **אבל הודיע** – סומן ידנית בכפתור סימון "הודיע" |
| 🔵 כחול | צ׳ק שהתקבל וממתין לפירעון |

לכל שורה יש גם פס צבע בצד, כך שאפשר לסרוק את הטבלה במבט. הכפתור ☀ בפינת הכותרת מחליף למצב בהיר.

**סימון "הודיע"**: על כל חודש בפיגור מופיע כפתור סימון "הודיע". לוחצים, כותבים מה נמסר
(ואם רוצים – עד מתי הבטיח לשלם), והחודש עובר מאדום לכתום. בלוח הבקרה יש שני מדדים נפרדים:
"פיגור ללא הודעה" ו"מאחרים שהודיעו", כך שרואים מיד על מי צריך ללחוץ.

### לוח בקרה (לפי חודש)
לכל דייר בשורה אחת: **כמה אמור להעביר** החודש, **כמה הועבר בפועל**, **באיזה אמצעי**, מה היתרה
ומה הפיגור המצטבר מחודשים קודמים. למעלה: צפי הגבייה לחודש, כמה נגבה, כמה ממתין לפירעון,
כמה פתוח וכמה בפיגור. אפשר לדפדף בין חודשים ולייצא ל-CSV (נפתח נכון באקסל, כולל עברית).

### חוזים
נכס + דייר + תקופה + שכר דירה + יום התשלום בחודש + אמצעי תשלום מוסכם + ביטחונות
(שטר חוב / ערבות / פיקדון) + **תוספות קבועות** (ועד בית, דמי ניהול, חניה…) שנוספות אוטומטית
לחיוב החודשי.

* **חיובים נוצרים אוטומטית בכל חודש** לפי החוזה – אין צורך להזין ידנית כל חודש.
* **חישוב יחסי** בחודש הראשון והאחרון לפי מספר הימים בפועל (ניתן לכיבוי בחוזה).
* עדכון שכר הדירה משנה רק חודשים עתידיים; חודשים שכבר חויבו נשארים כפי שהיו.
* אפשר להוסיף **חיוב חד־פעמי** (תיקון, ארנונה, קנס) לחודש מסוים, או לבטל חיוב.

### תשלומים
לכל תשלום נרשם: סכום, תאריך, אמצעי תשלום, ופרטים שתלויים באמצעי –
מספר צ׳ק / בנק / סניף / חשבון / תאריך פירעון, או אסמכתת העברה.

* **שיוך לחודשים**: אוטומטי לחוב הישן ביותר (כולל פריסה של תשלום גדול על כמה חודשים),
  או ידני לחודש מסוים, או ללא שיוך (מקדמה → מוצגת כיתרת זכות).
* **סטטוס**: שולם / ממתין לפירעון / חזר. תשלום שחזר לא נספר בגבייה.

### צ׳קים
מסך ייעודי לצ׳קים דחויים: מה ממתין לפירעון, מתי מועד הפירעון של כל צ׳ק, ומה כבר נפרע או חזר.
בלחיצה אחת מסמנים "נפרע" או "חזר". חודש שמכוסה בצ׳ק דחוי לא נספר כפיגור.

### חיפוש בחוזים
חיפוש חופשי בכל החוזים בבת אחת – בנוסח החוזה, בקבצים שהועלו, בהערות ובפרטי הדייר והנכס.
התוצאה מציגה את הקטע מהחוזה עם הדגשת המילים.

תחביר:

| דוגמה | משמעות |
|---|---|
| `אופציה הארכה` | שתי המילים חייבות להופיע באותו חוזה |
| `"ועד בית"` | ביטוי מדויק |
| `אופציה -ערבות` | כולל "אופציה", בלי "ערבות" |

החיפוש מתעלם מניקוד, מגרשיים עבריים (`״` = `"`), ממקף עברי ומאותיות סופיות – כך ש"שכירות"
יימצא גם בתוך "והשכירות" ו"שלום" יימצא גם כ"שלומ". בנוסף, בתוך עמוד החוזה יש שדה חיפוש
שמסמן תוצאות בתוך נוסח החוזה עצמו.

### קבצי חוזה
אפשר להעלות את החוזה כקובץ (PDF / Word / טקסט). המערכת מחלצת ממנו טקסט ומוסיפה אותו לחיפוש,
והקובץ המקורי נשמר וניתן לפתיחה בכל עת.

> **מגבלה**: PDF שהוא **סריקה/צילום** אינו מכיל טקסט, ולכן אי אפשר לחלץ ממנו כלום (זה דורש OCR).
> במקרה כזה המערכת תסמן "לא ניתן לחיפוש", ואפשר פשוט להדביק את נוסח החוזה בשדה
> **נוסח החוזה** – והחיפוש יעבוד עליו.

### כרטסת והדפסה
לכל חוזה יש כרטסת: כל החיובים והתשלומים לפי סדר כרונולוגי עם יתרה רצה, מוכנה להדפסה או
לשליחה לדייר.

### גיבוי
**הגדרות → הורדת גיבוי** מוריד קובץ JSON עם כל הנתונים, ואפשר לשחזר ממנו בחזרה.
קבצי החוזים המקוריים יושבים ב-`data/uploads` – כדאי לגבות גם את התיקייה הזו.

## איך זה מחשב

* כל הסכומים נשמרים **באגורות (מספר שלם)** – בלי שגיאות עיגול של מספרים עשרוניים.
* **יתרה לחודש** = סך החיובים לאותו חודש פחות התשלומים ששויכו אליו ונפרעו בפועל.
* **פיגור** = חוב שמועד התשלום שלו עבר ואין צ׳ק דחוי שמכסה אותו.
* **יתרת זכות** = כסף שהתקבל ולא שויך לאף חודש.
* חיובים נוצרים עד חודש קדימה, כדי שאפשר יהיה לראות מראש את החודש הבא.

## מבנה הקוד

```
rent/
├── server.js          שרת HTTP + הגשת הממשק (ללא תלויות)
├── src/
│   ├── db.js          סכימת SQLite ועזרי שאילתה
│   ├── domain.js      יצירת חיובים, שיוך תשלומים, יתרות ולוח בקרה
│   ├── api.js         נקודות ה-API, אימות קלט, ייצוא וגיבוי
│   ├── search.js      חיפוש מותאם עברית (נרמול, AND, ציטוט, החרגה, קטעי הקשר)
│   ├── extract.js     חילוץ טקסט מ-DOCX/PDF/TXT ללא ספריות
│   └── util.js        כסף, תאריכים ותקופות
├── public/            הממשק (HTML/CSS/JS רגיל, RTL)
├── test/              53 בדיקות אוטומטיות
└── data/              נוצר בהרצה: rent.db + uploads/ (לא נכנס ל-git)
```
